# VolleyTag Local

Локальный разметчик индивидуальной статистики волейбольного матча. Видео остаётся
на компьютере: приложение работает в браузере и не загружает исходник в облако.

## Возможности

- разметка приёма подачи, атаки, подачи, блока и защиты;
- отдельные исходы для эйса, выбитого приёма и блокаута;
- автоматическая фиксация таймкода, сета, счёта и комментария;
- горячие клавиши и управление воспроизведением;
- расчёт реализации и эффективности атаки, качества приёма и давления подачей;
- локальное автосохранение в браузере;
- экспорт событий в CSV и резервная копия в JSON;
- перемотка больших MP4 благодаря HTTP byte-range серверу.

## Быстрый запуск на macOS

1. Установите Python 3, если его ещё нет.
2. Скачайте репозиторий или клонируйте его.
3. Дважды нажмите `start.command`.
4. В браузере нажмите «Другое видео» и выберите файл матча.

Окно Терминала должно оставаться открытым во время работы. Чтобы остановить
приложение, закройте это окно или нажмите `Ctrl+C`.

## Запуск из терминала

```bash
python3 range_server.py 8765
```

Затем откройте <http://127.0.0.1:8765>.

## Схема разметки

| Элемент | Исходы |
| --- | --- |
| Приём подачи | идеальный, позитивный, негативный, ошибка |
| Атака | очко, в игре, блок соперника, ошибка |
| Подача | эйс, выбитый приём, в игре, ошибка |
| Блок | очко, касание, блокаут |
| Защита | в доводку, в игре, не поднял |

Определения можно адаптировать под методику конкретной команды. Приём подачи и
защита после атаки соперника намеренно учитываются отдельно.

## Данные и приватность

Видео не отправляется на внешний сервер. События хранятся в `localStorage`
браузера. Для переноса между компьютерами используйте резервную копию JSON.

Матчи, экспортированные CSV/JSON и другие пользовательские данные исключены из
репозитория через `.gitignore`.
