# VolleyTag Local

Локальный разметчик индивидуальной статистики волейбольного матча. Видео остаётся
на компьютере: приложение работает в браузере и не загружает исходник в облако.

## Возможности

- разметка приёма подачи, атаки, подачи, блока и защиты;
- отдельные исходы для эйса, выбитого приёма и блокаута;
- автоматическая фиксация таймкода, сета, счёта и комментария;
- горячие клавиши и управление воспроизведением;
- расчёт реализации и эффективности атаки, качества приёма и давления подачей;
- локальное автосохранение в браузере;
- экспорт событий в CSV и резервная копия в JSON;
- прямая отправка матча и всех событий в Google Sheets;
- голосовая разметка: короткое нажатие пробела управляет видео, удержание записывает команду;
- перемотка больших MP4 благодаря HTTP byte-range серверу.

## Быстрый запуск на macOS

1. Установите Python 3, если его ещё нет.
2. Скачайте репозиторий или клонируйте его.
3. Дважды нажмите `start.command`.
4. В браузере нажмите «Другое видео» и выберите файл матча.

Окно Терминала должно оставаться открытым во время работы. Чтобы остановить
приложение, закройте это окно или нажмите `Ctrl+C`.

## Голосовая разметка

1. Создайте бесплатный API-ключ в [Groq Console](https://console.groq.com/keys).
2. Создайте рядом с `start.command` файл `.groq-key` и вставьте в него только ключ.
3. Перезапустите `start.command`, разрешите браузеру доступ к микрофону.
4. Короткое нажатие пробела ставит видео на паузу; удержание пробела записывает фразу.

Например: «атака, забил, выиграли», «эйс», «атаку подняли», «приём позитивный,
проиграли». Звук используется браузером только для speech-to-text; в Groq
отправляется уже распознанный текст. Ключ и голосовые данные не попадают в Git.

## Запуск из терминала

```bash
python3 range_server.py 8765
```

Затем откройте <http://127.0.0.1:8765>.

## Подключение Google Sheets

1. Откройте нужную таблицу и выберите **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` кодом из [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
3. В настройках проекта Apps Script добавьте свойство сценария `VOLLEYTAG_TOKEN` со случайным длинным значением.
4. Выберите **Развернуть → Новое развертывание → Веб-приложение**: выполнять от своего имени, доступ — «Все».
5. Скопируйте URL `/exec`, вставьте его в блок Google Sheets в разметчике; туда же вставьте значение `VOLLEYTAG_TOKEN`.

Чтобы подключение автоматически подхватывалось в любом браузере, скопируйте
`config.example.js` в `config.local.js` и заполните URL и ключ. Локальный файл
исключён из Git и не попадёт в публичный репозиторий.

Ключ остаётся только в `localStorage` браузера и не попадает в репозиторий. Один
и тот же матч можно отправлять повторно: его строка и события обновятся без дублей.

## Схема разметки

| Элемент | Исходы |
| --- | --- |
| Приём подачи | идеальный, позитивный, негативный, ошибка |
| Атака | очко, в игре, блок соперника, ошибка |
| Подача | эйс, выбитый приём, в игре, ошибка |
| Блок | очко, касание, блокаут |
| Защита | в доводку, в игре, не поднял |

Определения можно адаптировать под методику конкретной команды. Приём подачи и
защита после атаки соперника намеренно учитываются отдельно.

## Данные и приватность

Видео не отправляется на внешний сервер. События хранятся в `localStorage`
браузера. Для переноса между компьютерами используйте резервную копию JSON.

Матчи, экспортированные CSV/JSON и другие пользовательские данные исключены из
репозитория через `.gitignore`.
