# Ручной fallback-разметчик VolleyTag

Этот интерфейс — ранний, но всё ещё рабочий слой проекта. Он полезен для ручной
статистики, проверки CV-кандидатов и работы без обученных весов.

## Возможности

- приём подачи: идеальный, позитивный, негативный, ошибка;
- атака: очко, в игре, блок соперника, ошибка;
- подача: эйс, выбитый приём, в игре, ошибка;
- блок: очко, касание, блокаут;
- защита: довёл до связки, просто поднял, не поднял;
- CSV/JSON, локальное хранение и синхронизация с Google Sheets.

## Голосовой ввод

Один ключ Groq используется для `whisper-large-v3-turbo` и текстовой модели
`openai/gpt-oss-20b`. Создай рядом со `start.command` файл `.groq-key` с одним
ключом либо задай `GROQ_API_KEY`. Файл исключён из Git.

```bash
umask 077
pbpaste > .groq-key
```

Примеры: «атака, забил», «подал эйс», «принял переходящий мяч, довёл до
связки». Короткий аудиофрагмент отправляется провайдеру только во время
удержания `Space`; исходное видео не отправляется.

## Google Sheets

1. Скопируй `google-apps-script/Code.gs` в Apps Script нужной таблицы.
2. Добавь свойство сценария `VOLLEYTAG_TOKEN`.
3. Разверни сценарий как веб-приложение.
4. Укажи URL и токен в интерфейсе либо скопируй `web/config.example.js` в
   `config.local.js` и заполни локальные значения.

`config.local.js`, `.groq-key`, видео, экспорты и голосовые логи не должны
попадать в Git.
